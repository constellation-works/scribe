# Changelog — STD-14 Pre-release legacy support

Version history of [STD-14](STD-14.md). Adopting repos pin the `version:` in its frontmatter as `STD-14@<version>`; a version changes only when a rule is added, removed or changed in meaning.

- **v1 (2026-11-26):** initial publication, R1–R2 (no legacy support before a repository's first release tag; legacy duties begin at the first release tag) (scribe standard-24, ORB-28767).
