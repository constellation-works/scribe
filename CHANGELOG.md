# Changelog

All notable changes to scribe. Compiled at release time from merged work;
tasks do not edit this file.

## Unreleased

- **Breaking (phase 2 catchers, ORB-26651):** a tag's
  `[tags.<tag>.capture]` is a catcher with `from` (`user`, `assistant` or
  `both`; `daniel` still reads as `user`, with a warning), `route`
  (`propose` or `write`) and `max_open` (open claims per tag, 1–20, default
  10); `tag show` prints `max_open`. The shipped set is exactly
  `preferences` and `standard` (which now catches "as a standard", "every
  repo", …); `idea` no longer ships and, with `issue`, is a config example
  in [specs/catchers.md](docs/design/scribe/specs/catchers.md). Stored
  `idea-<n>` entries stay readable. Removed, with no alias:
  - the `scribe issue` noun: `issue add`, `occur`, `update`, `move`,
    `search`, `show`, `list` and `issue stats` (exit 2 as unknown
    commands);
  - `route = "agent"` (a table that uses it loads with a warning and
    catches nothing) and the prompt hook's root-cause line;
  - `#scribe forget <issue-id>` and `#scribe forget <issue-id>#<n>`
    (`#scribe forget issue-<n>` now forgets the entry an issue became);
  - `scribe search --kind issue`, `question ask --kind issue` and the
    `scribe.ask` scope kind `issue`;
  - `ask`'s issue evidence, and the error codes `issue_not_found`,
    `occurrence_not_found`, `issue_forgotten` and `reserved_tag`.

  Stored issues convert to `issue` entries with no model call on the
  first write (title, cause and fix as content; the first request as the
  quote; occurrence sessions as related), and their files move to
  `pre-issue-<date>/`.
- **Breaking:** `scribe record search` is removed with no alias; run
  `scribe search` instead, with the same arguments, flags and output. The
  `record` noun is gone ([4_decisions.md](docs/design/scribe/4_decisions.md#search-is-a-top-level-verb)).
- Initial version from the constellation Rust CLI template: `note add`,
  `note list`, `note show`, and an audit log of mutating commands
  (`audit.jsonl` in the data directory).
