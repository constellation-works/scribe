Retire an item with a reason: off the page, lists and ask, text kept

Usage: scribe memory retire [OPTIONS] --author <NAME> --reason <TEXT> <ID>

Arguments:
  <ID>  The item (its id or a unique prefix of at least four characters)

Options:
      --author <NAME>  Your crew or model name
      --reason <TEXT>  Why it no longer applies, 1-300 characters
  -h, --help           Print help
  -V, --version        Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

Hides an item from the page, lists and ask; its text is kept. Run it when
the user says an item is wrong; the next time they say it, a fresh item opens.

Examples:
  scribe memory retire <id> --author opus --reason 'The user says this is wrong'
