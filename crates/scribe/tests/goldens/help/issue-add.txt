Record a new issue with its first occurrence (no approval; Daniel forgets what is wrong)

Usage: scribe issue add [OPTIONS] --author <AUTHOR> --title <TITLE> --signature <TEXT> --summary <SUMMARY>

Options:
      --author <AUTHOR>    Agent name
      --title <TITLE>      The issue's title (at most 120 characters)
      --signature <TEXT>   A symptom or error string a later search should match, repeatable (1 to 5, 200 characters each)
      --topic <TOPIC>      Topic, repeatable (at most five)
      --related <REF>      Reference, repeatable: session:<id> names the session Daniel's request was typed in; task:<id>, pr:<owner>/<repo>#<n> and repo:<slug> are linked
      --request <WORDS>    Daniel's request, word for word from one of his typed turns in the session --related names
      --summary <SUMMARY>  What happened, in your words (at most 1200 characters)
      --error-line <LINE>  A key error line, repeatable (at most 10, 300 characters each); shown as your evidence
      --cause <CAUSE>      The cause this occurrence found [default: cause not found]
      --fix <FIX>          The fix or mitigation it applied [default: fix not found]
      --project <PROJECT>  The project it happened in (a repository slug, or global) [default: global]
  -h, --help               Print help
  -V, --version            Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

Search first (scribe issue search); add only when no issue matches, else
occur. --request is Daniel's request word for word from one of his typed
turns in the session --related session:<id> names. Error lines are your
evidence and are shown as such. Without a known cause, leave --cause out:
it reads "cause not found". Daniel cancels with #scribe forget <issue-id>.

Examples:
  scribe issue add --author opus --related session:<id> --request '<his words>' --title '<title>' --signature 'HTTP 429' --summary '<what happened>'
  scribe issue add --author opus --related session:<id> --related task:<id> --request '<his words>' --title '<title>' --signature 'HTTP 429' --signature 'secondary rate limit' --summary '<what happened>' --error-line '<a key error line>' --cause '<the cause>' --fix '<the fix>' --project orbit
