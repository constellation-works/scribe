Write every session to a directory as Markdown or JSONL

Writes every session to a directory you name, as Markdown in the old record files' shape or as JSONL, one line per row; the backup and the way out, writing nothing to the store.

Usage: scribe export [OPTIONS] <DIR>

Arguments:
  <DIR>
          Directory to write into: created owner-only, or refused unless empty

Options:
      --as <FORMAT>
          markdown or jsonl [default: markdown]

          Possible values:
          - markdown: One file per session, sessions/<yyyy>/<mm>/<id>.md, and control.json
          - jsonl:    One line per row, <table>.jsonl per table

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Examples:
  scribe export ~/scribe-export
  scribe export --as jsonl ~/scribe-export-jsonl
  scribe export ~/scribe-export --json | jq '.files | length'
