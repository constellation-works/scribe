Search every stored record for words, ranked as question ask ranks them, with no model call

Usage: scribe record [OPTIONS] <COMMAND>

Commands:
  search  Rank entries, session headers and segments for words, best first, with no model call
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

Global options:
      --root <DIR>       Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>  Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json             Shorthand for --format json

Examples:
  scribe record search "merge queue"
  scribe record search release --kind session --since 2026-11-01
  scribe record search "api" --json | jq -r '.hits[].cite'
