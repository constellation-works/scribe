Switch a past session on and catalog its transcript

Switches a past session on by name and catalogs every window of its transcript.

Usage: scribe session catalog [OPTIONS] --author <NAME> <ID>

Arguments:
  <ID>
          The transcript's id, or a unique prefix of it (at least four characters)

Options:
      --author <NAME>
          Who is asking: lowercase letters, digits, '.', '_' or '-', 1-40 characters

      --project <PROJECT>
          Record this project instead of the transcript's attribution [default: the attribution transcript list would use]

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Switches one past session on with cataloged_by and runs every window, with
no deadline. Refuses a session that already has a record or a /scribe on
switch. A transcript whose last message is at least a day old is marked
final and switched off; a newer one stays on and due. A failed catalog
keeps its checkpoint; run the same command again to resume. Writes no entries.

A new catalog is recorded as kind agent under --author; the reserved names
daniel, scribe and consistency are refused. Daniel catalogs as himself by
typing /scribe catalog <id> in his prompt; running this command on that
session afterwards runs its windows and keeps cataloged_by daniel.

Examples:
  scribe session catalog <id> --author opus
  scribe session catalog <id> --author opus --project scribe
  scribe session catalog <id> --author opus --json | jq '.passes[0].result'
