List, show and write session records cataloged with /scribe on

Lists and shows cataloged session records, and writes them with pass and catalog.

Usage: scribe session [OPTIONS] <COMMAND>

Commands:
  list          List session records, newest first
  show          Show one session record
  pass          Settle due or named sessions when no new window needs distillation
  pass-prepare  Prepare one session window or settle a session without a model
  pass-apply    Verify a supplied session answer and apply it or request a retry
  rebuild       Check a session rebuild and name the job that runs it
  deactivate    Hide an outdated session with a reason
  activate      Show an inactive session or pin it against hiding
  catalog       Switch a past session on for cataloging
  help          Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; picks [models] or [codex.models] for model calls [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Examples:
  scribe session list --project scribe
  scribe session show <id>
  scribe session deactivate <id> --author opus --reason 'the feature was removed'
  scribe session pass --json
