Read entries and write agent notes

Usage: scribe entry [OPTIONS] <COMMAND>

Commands:
  add     Add an agent note (never attributed to Daniel)
  update  Update content or metadata; Daniel's entries allow metadata only
  retire  Retire an agent note with a reason
  list    List entries, oldest first
  show    Show one entry in full: what was said, its content and its cite
  pickup  Record that a consumer picked up an action entry, or that its result was rejected
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

Examples:
  scribe entry list --tag decisions
  scribe entry list --status active --project scribe
  scribe entry show <id>
