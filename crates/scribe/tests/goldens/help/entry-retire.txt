Retire an entry with a reason

Retires an agent note, or the user's entry on their instruction.

Usage: scribe entry retire [OPTIONS] --author <AUTHOR> --reason <REASON> <ID>

Arguments:
  <ID>
          Entry id or unique prefix

Options:
      --author <AUTHOR>
          Agent name

      --reason <REASON>
          Why the note no longer applies

      --session <ID>
          The session you run in, whose transcript holds the user's instruction; requires --instruction

      --instruction <WORDS>
          The user's instruction, word for word from one of their last three typed turns of --session within 30 minutes, naming the id (or answering your reply that names it) and the act; requires --session

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

The user's entry retires only on their instruction: --session and --instruction.

Examples:
  scribe entry retire <id> --author opus --reason 'No longer applies'
  scribe entry retire <id> --author opus --reason 'The user asked' --session <id> --instruction '<their words>'
