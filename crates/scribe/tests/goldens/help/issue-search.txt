Rank issues for words, best first, with no model call

Usage: scribe issue search [OPTIONS] <TERMS>

Arguments:
  <TERMS>  The words to look for: symptoms or error text

Options:
      --project <PROJECT>  Only issues that occurred in this project [default: any]
      --topic <TOPIC>      Only issues carrying this topic; repeat it to require every one [default: any]
      --limit <N>          Show at most this many hits, 1 or more [default: 20]
  -h, --help               Print help
  -V, --version            Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

Ranks issues by their titles, signatures, causes, fixes and occurrences with
BM25, as scribe search --kind issue does, with no model call. Run it before
diagnosing.

Examples:
  scribe issue search 'HTTP 429 secondary rate limit'
  scribe issue search 'cpu exhausted' --project orbit --json | jq -r '.hits[].cite'
