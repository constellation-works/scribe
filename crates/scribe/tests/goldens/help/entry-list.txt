List entries, oldest first

Usage: scribe entry list [OPTIONS]

Options:
      --tag <TAG>           Only entries filed under this tag, by its name as `tag list` prints it [default: any]
      --status <STATUS>     Only entries with this status [default: any] [possible values: active, superseded, retired, forgotten]
      --project <PROJECT>   Only entries recorded in this project (a repository slug, or global) [default: any]
      --group <ID>          Only entries of member sessions in this group (id, unique prefix, or project group slug)
      --topic <TOPIC>       Only entries carrying this topic; repeat it to require every one [default: any]
      --related <REF>       Only entries mentioning this reference (task:<id>, pr:<owner>/<repo>#<n>, repo:<slug> or session:<id>, whose id may be a unique prefix); repeat it to accept any of them [default: any]
      --since <DATE>        Only records on or after this day, YYYY-MM-DD [default: no lower bound]
      --until <DATE>        Only records on or before this day, YYYY-MM-DD [default: no upper bound]
      --after <TIME>        Only entries created strictly after this instant (RFC 3339, such as 2026-11-15T09:00:00Z): an intake's cursor [default: any]
      --window              Include each entry's transcript window (an action entry's chat before its #scribe line) [default: left out]
      --author <NAME>       Only entries written under this author name, such as user or an agent's --author [default: any]
      --author-kind <KIND>  Only entries written through this channel: user (a #scribe line or an approval), agent (entry add) or scribe (an idea the session pass captured) [default: any] [possible values: user, agent, scribe]
      --limit <N>           Show at most this many of the matching entries, 1 or more; --json reports the total and whether the list was cut [default: all]
  -h, --help                Print help
  -V, --version             Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

Examples:
  scribe entry list
  scribe entry list --tag preferences --status active
  scribe entry list --topic ci --limit 10
  scribe entry list --since 2026-10-01 --until 2026-10-31 --author-kind user
  scribe entry list --related task:<id> --related pr:<owner>/<repo>#<n>
  scribe entry list --tag standard --after 2026-11-15T09:00:00Z --window --json
  scribe entry list --json | jq '.entries[].content'
  scribe entry list | cut -f1,6
