Show memory's fixed rules

Shows memory's fixed rules and values; memory has no switches.

Usage: scribe memory rules [OPTIONS]

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; picks [models] or [codex.models] for model calls [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Prints memory's fixed rules: how many items a pass writes, how many undated
candidates a session holds, how long a now item stays after its date, the
milestone lines shown, the profile's length and the phrases that make an
event a milestone. Memory has no switches.

Examples:
  scribe memory rules
  scribe memory rules --json | jq '.rules[] | {rule, value}'
