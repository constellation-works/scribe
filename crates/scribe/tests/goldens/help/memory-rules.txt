Show active memory promotion rules and windows

Shows the promotion rules and page windows in effect, each with its origin.

Usage: scribe memory rules [OPTIONS]

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Prints the rules that promote a now item to milestones and the windows
after which an item leaves the session-start page, each with its value
and where it came from: shipped, or config with the file and line. Set
them under [memory] and [memory.promote] in config.toml.

Examples:
  scribe memory rules
  scribe memory rules --json | jq '.rules[] | {rule, value}'
