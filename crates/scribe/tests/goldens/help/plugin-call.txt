Run one Orbit plugin tool call from stdin

Reads an exec envelope on stdin and writes one reply envelope on stdout.

Usage: scribe plugin call [OPTIONS]

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; picks [models] or [codex.models] for model calls [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Reads one Orbit exec envelope on stdin and prints one reply envelope on
stdout, exiting 0 whenever a reply was printed. The store is the plugin's
[plugins.scribe] root setting, an absolute path.

Examples:
  printf '%s' '{"schema_version":1,"tool":"scribe.session-pass","input":{},"context":{"config":{"root":"/home/me/.scribe"}}}' | scribe plugin call
