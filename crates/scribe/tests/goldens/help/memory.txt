Show what scribe noticed about the user and manage memory items

Shows what scribe has noticed about the user from switched-on sessions, and lets you acknowledge, retire or forget an item.

Usage: scribe memory [OPTIONS] <COMMAND>

Commands:
  show     Show the memory block, one memory file, or a profile revision
  rules    Show memory's fixed rules
  ack      Mark a now item as raised in this session
  forget   Forget a now item or milestone for good
  restore  Write a stored profile revision back as the profile
  refresh  Run deterministic refresh checks or point to the Orbit refresh job
  prepare  Prepare bounded profile refresh inputs and optimistic basis
  apply    Validate and commit a rebuilt profile answer from stdin JSON
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; picks [models] or [codex.models] for model calls [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Memory is one fixed shape: memory/profile.md, rebuilt weekly by the
scribe-memory-refresh Orbit job; memory/now/, dated things the user plans,
attends or must meet, written by the session pass of a session switched on
with /scribe on; and memory/milestones/. It describes, it never binds: rules
are their preferences entries.

Examples:
  scribe memory show
  scribe memory show profile
  scribe memory show 2026-12-01-hackathon-deadline
  scribe memory ack 2026-12-01-hackathon-deadline --session <id> --author opus
  scribe memory refresh
  scribe memory prepare --json
