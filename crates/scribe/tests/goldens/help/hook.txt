Run a provider hook for session and prompt events

Runs a provider hook to record #scribe lines and settle proposals, switch /scribe on and off, mark session passes due, and report open proposals.

Usage: scribe hook [OPTIONS] <COMMAND>

Commands:
  session-start       Handle the SessionStart hook JSON from stdin
  user-prompt-submit  Handle the UserPromptSubmit hook JSON from stdin
  stop                Handle the Stop hook JSON from stdin
  session-end         Handle the SessionEnd hook JSON from stdin
  help                Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; picks [models] or [codex.models] for model calls [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

These run from provider packages or scribe init hooks, not by hand.
Use --provider codex for Codex; the default is claude-code.

Examples:
  scribe hook session-start < <payload.json>
  scribe hook user-prompt-submit < <payload.json>
  scribe hook stop < <payload.json>
  scribe hook session-end < <payload.json>
