Read the user's recorded preferences, and the records of the sessions they cataloged

Usage: scribe [OPTIONS] <COMMAND>

Setup:
  init         Scaffold the embedded skill and selected provider hooks

Records:
  entry        Read entries and write agent notes
  session      List, show and write session records cataloged with /scribe on
  proposal     Read, open, update and settle proposals
  memory       Show what scribe noticed about the user and manage memory items
  issue        Record and search recurring incidents across projects
  tag          List tags and manage agent-created store tags

Find:
  brief        Show the session-start page: memory, recent sessions, open claims
  question     Answer a question from the records with verbatim quotes
  search       Search every stored record by words, with no model call
  transcript   List uncataloged provider transcripts and show one, writing nothing
  tmux         Browse sessions, entries and proposals in an fzf popup

Upkeep:
  consistency  Propose superseding or retiring entries via scan

Integration:
  hook         Run a provider hook for session and prompt events
  plugin       Serve the Orbit plugin's tools (the plugin backend runs this)

Options:
  -h, --help     Print help
  -V, --version  Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

Examples:
  scribe entry list --tag preferences --status active
  scribe entry show <id> --json
  scribe session list --project scribe
  scribe proposal list
  scribe consistency scan --json
  scribe tag list
  scribe search "merge policy" --kind session --since 2026-11-01
  scribe question ask "how do we merge agent PRs?"
  scribe entry list | cut -f1,6

Exit status: 0 on success, 1 when a command fails, 2 on a usage error.
