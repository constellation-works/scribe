Read Daniel's recorded decisions and preferences, and the records of the sessions he cataloged

Usage: scribe [OPTIONS] <COMMAND>

Commands:
  entry     List and show the entries recorded with #scribe
  session   List and show the records of sessions cataloged with /scribe on
  proposal  List what the consistency routine proposes changing
  tag       List the tags entries are filed under
  hook      Run a Claude Code hook: record #scribe lines and fill in their cites
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

Global options:
      --root <DIR>       Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>  Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json             Shorthand for --format json

Examples:
  scribe entry list --tag decisions --status active
  scribe entry show <id> --json
  scribe session list --project scribe
  scribe proposal list
  scribe tag list
  scribe entry list | cut -f1,6

Exit status: 0 on success, 1 when a command fails, 2 on a usage error.
