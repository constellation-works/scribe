Check a session rebuild and name the job that runs it

Checks that a session record can be rebuilt from its transcript and prints the Orbit job command that rebuilds it, resuming interrupted windows.

Usage: scribe session rebuild [OPTIONS] --author <NAME> <ID>

Arguments:
  <ID>
          Session record to replace: its id or a unique prefix of it (at least four characters)

Options:
      --author <NAME>
          Name of the agent requesting the rebuild (lowercase letters, digits, '.', '_' or '-')

      --confirm
          Confirm replacing the current header and log

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; picks [models] or [codex.models] for model calls [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Checks what the rebuild refuses (a forgotten session, a missing --confirm, a
session a pass owns, a missing or unproven transcript) and prints the Orbit
job command. The job replaces the header and log only after every transcript
window succeeds; a failed or interrupted run keeps its private checkpoint,
and running the job again resumes it.

Examples:
  scribe session rebuild <id> --author <name> --confirm
  orbit job run scribe-session-rebuild --input '{"session":"<id>","author":"<name>","confirm":true}'
