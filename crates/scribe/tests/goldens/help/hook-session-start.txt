Handle the SessionStart hook JSON from stdin

Tells the user how many proposals are open, which action entries are unpicked, and when this session may continue a recorded one, from the SessionStart hook's JSON on stdin.

Usage: scribe hook session-start [OPTIONS]

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Reads the SessionStart payload (session_id, cwd, source and transcript_path).
Reports open proposals, unpicked actions and possible recorded predecessors.
Interactive Claude sessions receive the brief. After a clear with a continue
handoff, the hook prepends that handoff and links the sessions, carrying the
recording switch. Calls no model.

Examples:
  scribe hook session-start < <payload.json>
