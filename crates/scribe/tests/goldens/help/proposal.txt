Read, open, update and settle proposals

Usage: scribe proposal [OPTIONS] <COMMAND>

Commands:
  add     Open a proposal, including against a Daniel entry
  update  Update the reason of an open agent proposal
  settle  Approve or reject a proposal about an agent entry
  list    List every proposal by id and its settlement state
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

Global options:
      --root <DIR>       Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>  Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json             Shorthand for --format json

Examples:
  scribe proposal list
  scribe proposal list --json | jq '.proposals[] | select(.state == "open")'
