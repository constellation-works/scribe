List uncataloged provider transcripts and show one, writing nothing

Usage: scribe transcript [OPTIONS] <COMMAND>

Commands:
  list  List uncataloged transcripts, newest first, writing nothing
  show  Show one transcript and the user's first five turns, writing nothing
  help  Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

Lists provider transcripts that have no session record and no switch,
selected with --provider codex or claude-code (the default),
newest first, and writes nothing. --min-turns defaults to 20. project is
the configured [projects.<slug>] path with the most mentions, else the
cwd's project. show prints one transcript with the user's first five turns.

Examples:
  scribe transcript list --since 2026-10-01 --project scribe
  scribe transcript list --since 2026-10-01 --until 2026-10-31 --min-turns 40
  scribe transcript show <id>
  scribe transcript list --since 2026-10-01 --json | jq '.transcripts[].session'
