Count trigger fires, issue writes and withdrawals, for recall and precision

Usage: scribe issue stats [OPTIONS]

Options:
      --since <DATE>  Count fires and writes from this day on (YYYY-MM-DD) [default: the whole log]
  -h, --help          Print help
  -V, --version       Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

Counts from the audit log, with no model call: issue trigger fires, the
fires an issue write on the same turn followed, writes no fire matched,
and writes later forgotten or moved. The two ratios are proxies: precision
is writes neither forgotten nor moved / writes, trigger yield is fires that
led to a write / fires. Investigations no trigger fired on and no agent
recorded are not counted.

Examples:
  scribe issue stats
  scribe issue stats --since 2026-11-01 --json | jq '.precision_proxy.value'
