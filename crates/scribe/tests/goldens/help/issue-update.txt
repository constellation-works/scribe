Change an issue's cause, fix or status

Usage: scribe issue update [OPTIONS] --author <AUTHOR> <ID>

Arguments:
  <ID>  Issue id or unique prefix (at least four characters)

Options:
      --author <AUTHOR>  Agent name
      --cause <CAUSE>    The best-known cause (at most 600 characters)
      --fix <FIX>        The current best fix or mitigation (at most 600 characters)
      --status <STATUS>  The new status [possible values: open, mitigated, resolved]
      --related <REF>    Reference, repeatable: session:<id> names the session the user's request was typed in; task:<id>, pr:<owner>/<repo>#<n> and repo:<slug> are linked
      --request <WORDS>  The user's request, word for word from one of their typed turns in the session --related names
  -h, --help             Print help
  -V, --version          Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

Examples:
  scribe issue update <issue-id> --author opus --cause '<the cause found>' --fix '<the fix>' --status resolved
  scribe issue update <issue-id> --author opus --status mitigated --related session:<id> --request '<their words>'
