Show one session record: its metadata, links, children, header and the log's table of contents

Usage: scribe session show [OPTIONS] <ID>

Arguments:
  <ID>  The session's id, as printed by `session list`, or a unique prefix of it (at least four characters), or a cite: session:<id>, or session:<id>#<n> for one segment

Options:
      --log          Print every segment's text after the log's table of contents
      --segment <N>  Print only segment N of the log, with its text (from 1)
  -h, --help         Print help
  -V, --version      Print version

Global options:
      --root <DIR>       Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>  Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json             Shorthand for --format json

Examples:
  scribe session show <id>
  scribe session show <id> --log
  scribe session show <id> --segment 2
  scribe session show 'session:<id>#2'
  scribe session show <id> --json | jq -r '.log[].heading'
