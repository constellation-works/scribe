List #scribe markers with no entry from scribe

Usage: scribe mark list [OPTIONS]

Options:
      --session <SESSION>  Only this session's markers: a provider session id or a unique prefix [default: every session]
  -h, --help               Print help
  -V, --version            Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; picks [models] or [codex.models] for model calls [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

A marker is listed when scribe wrote no entry for it: handed to the agent to
record (outcome refused, code agent_handoff), or left from before scribe
stopped calling a model for markers: pending (the session's next reply hands
it over) or given up (code model_failed). It holds ids only; the line it
marks is in the session's transcript. Whether the agent recorded it is in
scribe entry list.

Examples:
  scribe mark list
  scribe mark list --session <id> --json
