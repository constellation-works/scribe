List the #scribe markers not cataloged yet and retry them

Lists the #scribe markers whose model call is pending or gave up, and catalogs a session's again from a shell with model credentials.

Usage: scribe mark [OPTIONS] <COMMAND>

Commands:
  list  List #scribe markers with no entry from scribe
  help  Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; picks [models] or [codex.models] for model calls [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Examples:
  scribe mark list
  scribe mark list --session <id> --json
