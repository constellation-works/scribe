Update an entry's content or metadata

Updates content or metadata; user entries and approved claims allow metadata only.

Usage: scribe entry update [OPTIONS] --author <AUTHOR> <ID>

Arguments:
  <ID>
          Entry id or unique prefix (at least four characters)

Options:
      --author <AUTHOR>
          Agent name

      --content <CONTENT>
          Replacement content

      --option <OPTIONS>
          Replace a decision's options in full, repeatable

      --clear-options
          Clear a decision's options and recommendation

      --recommended <RECOMMENDED>
          Set the 1-based recommendation for a decision

      --rationale <RATIONALE>
          Replace an agent decision's rationale

      --add-topic <ADD_TOPIC>
          Topic to add, repeatable

      --remove-topic <REMOVE_TOPIC>
          Topic to remove, repeatable

      --add-related <ADD_RELATED>
          Reference to add, repeatable

      --remove-related <REMOVE_RELATED>
          Reference to remove, repeatable

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; picks [models] or [codex.models] for model calls [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Examples:
  scribe entry update <id> --author opus --add-topic api
