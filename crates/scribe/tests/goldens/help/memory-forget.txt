Forget a now item or milestone for good

Removes a now item or milestone file for good, with its history.

Usage: scribe memory forget [OPTIONS] --author <NAME> <ID>

Arguments:
  <ID>
          The now item's or milestone's file stem

Options:
      --author <NAME>
          Your crew or model name

      --confirm
          Confirm removing it for good; it cannot be undone

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Removes a now item or milestone for good, with its history; it cannot be
undone, so it needs --confirm. The profile is corrected by editing
memory/profile.md: the next refresh takes the edit as the user's correction.

Examples:
  scribe memory forget 2026-12-01-hackathon-deadline --author opus --confirm
