Propose superseding or retiring entries via scan

Proposes superseding or retiring entries a later one replaced or that are due for review, and deactivates stale or removed-feature sessions via scan.

Usage: scribe consistency [OPTIONS] <COMMAND>

Commands:
  scan  Propose retiring entries due for review and deactivate stale sessions
  help  Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

Examples:
  scribe consistency scan
  scribe consistency scan --json | jq '.opened[].id'
