Group sessions into named seats for a shared piece of work

Usage: scribe group [OPTIONS] <COMMAND>

Commands:
  open   Open a group on a verbatim quote from the calling session
  join   Join a named seat under your own author name
  leave  Remove the calling session from its seat
  close  Summarize and close the group from the session that opened it
  show   Show one group, its references and its seat chains
  list   List groups newest first with their rosters
  help   Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

Examples:
  scribe group open --title 'Release review' --kind review --project scribe --quote 'open a release review'
  scribe group join <id> --as editor --author aide --role reviewer
  scribe group close <id>
  scribe group show <id> --json
