Write the record of each session whose pass is due, or of the sessions named, with the session model

Usage: scribe session pass [OPTIONS]

Options:
      --session <ID>  Pass this session (its id or a unique prefix of at least four characters) now, ignoring retry backoff and whether a pass is due (it must be switched on); repeat for several [default: every due session, at most five]
  -h, --help          Print help
  -V, --version       Print version

Global options:
      --provider <PROVIDER>  Transcript provider for hooks, discovery and catalog; model routing for global ask/consistency [default: claude-code; allowed: claude-code, codex]
      --root <DIR>           Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>      Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json                 Shorthand for --format json

The plugin routine ships disabled; once enabled on a host it runs every
5 minutes. Also run this command by hand where each configured provider CLI
is on PATH. Each session uses its stored provider (Codex defaults to Luna). Takes
at most five due sessions per run, processing every new-message window
(default 40 messages / 15000 characters; [catalog] window_messages and
window_chars). Each window rewrites the header and open segment, appends
new segments and checkpoints the record. Sealed segments stay unchanged;
[catalog] segment_windows (default 3) bounds how long a segment stays open.
--json reports windows, segments, seals and how many due sessions remain.
Also proposes up to 3 unmarked preferences per session per run,
until 20 candidate proposals are open. Review with scribe proposal list;
only a typed #scribe approve <id> writes Daniel's entry; #scribe reject <id>
drops it. Writes up to 5 findings per session per run itself: an assistant
turn's measured or verified result, copied verbatim (at most 4000
characters), authored by the assistant; remove one with #scribe retire <id>.
The FINDINGS and SUPERSEDED columns (findings and superseded in --json)
name them. First settles open finding candidates as findings and closes
candidates under a tag the store no longer defines (settled in --json).
A failed pass stays due with automatic retry delays of 5, 10, 20, 40,
then at most 60 minutes. --session retries immediately. Exits 1 when any
pass failed, naming each failed session, its error code and short reason.

Examples:
  scribe session pass
  scribe session pass --session <id> --session <id>
  scribe session pass --json | jq '.passes[] | select(.result == "failed")'
