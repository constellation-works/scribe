Write the record of each session whose pass is due, or of the sessions named, with the session model

Usage: scribe session pass [OPTIONS]

Options:
      --session <ID>  Pass this session now, whether or not a pass is due (it must be switched on); repeat for several [default: every due session, at most five]
  -h, --help          Print help
  -V, --version       Print version

Global options:
      --root <DIR>       Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>  Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json             Shorthand for --format json

Run it by hand, from a shell where claude is on PATH. Processes at most
five due sessions per run; --json reports what each pass did and how many
due sessions remain. Calls the configured session model. A failed pass
stays due: run the command again to retry it. Exits 1 when any pass
failed, naming each failed session and its error code on stderr.

Examples:
  scribe session pass
  scribe session pass --session <id> --session <id>
  scribe session pass --json | jq '.passes[] | select(.result == "failed")'
