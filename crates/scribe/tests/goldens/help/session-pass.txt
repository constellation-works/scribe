Settle due or named sessions when no new window needs distillation

Settles eligible sessions deterministically and prints the Orbit job command when new windows need distillation.

Usage: scribe session pass [OPTIONS]

Options:
      --session <ID>
          Settle this switched-on session, even during backoff; accepts a unique prefix of at least four characters and can be repeated

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Global options:
      --provider <PROVIDER>
          Transcript provider for hooks, discovery and catalog; picks [models] or [codex.models] for model calls [default: claude-code; allowed: claude-code, codex]

      --root <DIR>
          Data directory [default: $SCRIBE_ROOT, else ~/.scribe]

      --format <FORMAT>
          Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto]
          
          [possible values: auto, table, json]

      --json
          Shorthand for --format json

The scribe-session-pass Orbit routine ships disabled. Once enabled on a
configured host it runs every five minutes. Run the job by hand to distill
new windows. It takes up to five due sessions per run and checkpoints each
window before reading the next. Named sessions bypass retry backoff.

Examples:
  scribe session pass
  scribe session pass --session <id> --json
  orbit job run scribe-session-pass
  orbit job run scribe-session-pass --input 'sessions=["<id>"]'
