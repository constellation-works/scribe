Add a note and print it

Usage: scribe note add [OPTIONS] <TITLE>

Arguments:
  <TITLE>  The note's title: one line, at most 200 characters

Options:
      --body <TEXT>          Longer text, shown by `note show` and in --json output; not blank [default: none]
      --tag <TAG>            Label the note; repeat for several (lowercase letters, digits, '-')
      --priority <PRIORITY>  How much it matters [default: normal] [possible values: low, normal, high]
  -h, --help                 Print help
  -V, --version              Print version

Global options:
      --root <DIR>       Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>  Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json             Shorthand for --format json

Examples:
  scribe note add "Buy milk"
  scribe note add "Draft the report" --tag work --tag writing --priority high
  scribe note add "Ideas" --body "longer text, shown by note show" --json
