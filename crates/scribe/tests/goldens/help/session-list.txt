List session records, oldest first, with whether a pass is due

Usage: scribe session list [OPTIONS]

Options:
      --project <PROJECT>  Only sessions that ran in this project (a repository slug) [default: any]
      --topic <TOPIC>      Only sessions carrying this topic [default: any]
      --limit <N>          Show at most this many of the matching sessions, 1 or more; --json reports the total and whether the list was cut [default: all]
  -h, --help               Print help
  -V, --version            Print version

Global options:
      --root <DIR>       Data directory [default: $SCRIBE_ROOT, else ~/.scribe]
      --format <FORMAT>  Output format; auto is a table on a terminal, tab-separated lines otherwise, and json is one JSON document [default: $SCRIBE_FORMAT, else auto] [possible values: auto, table, json]
      --json             Shorthand for --format json

Examples:
  scribe session list
  scribe session list --topic release --limit 5
  scribe session list --json | jq '.sessions[] | select(.due)'
